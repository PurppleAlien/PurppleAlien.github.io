\section*{Proyecto Terminal I: Sistema de Detecci\'{o}n de Par\'{a}frasis y Plagio (Tesis de Titulaci\'{o}n)}
\justifying
\small
Sistema NLP de doble modo (clasificaci\'{o}n por pares + an\'{a}lisis de documentos completos) para detecci\'{o}n de plagio acad\'{e}mico en la UAM-I: corpus institucional TESIUAMI de \textbf{21{,}128 tesis} de las tres divisiones (CBI, CBS y CSH) m\'{a}s un corpus cient\'{i}fico externo de $\sim$250 millones de obras (OpenAlex, Semantic Scholar y Crossref).
\vspace{0.12cm}
\begin{itemize}
    \item \textbf{Arquitectura:} recuperaci\'{o}n h\'{i}brida (sem\'{a}ntica con HNSW + l\'{e}xica con BM25, fusi\'{o}n RRF) + clasificador cruzado (cross-encoder) cuantizado a int8, con modelos XLM-RoBERTa/BETO afinados.
    \item \textbf{Modelos:} BETO v3 fine-tuned (\textbf{F1 = 0.842} sobre el conjunto de prueba limpio), evaluado con intervalos de confianza (IC95\%) y auditor\'{i}a de fuga de datos; empata la l\'{i}nea base previa con \'{o}rdenes de magnitud menos datos anotados.
    \item \textbf{Hallazgo:} la tesis central es \emph{``el dato supera a la arquitectura''}: los datos sint\'{e}ticos degradan el desempe\~{n}o y la b\'{u}squeda exhaustiva muestra que el corpus es original — la similitud tem\'{a}tica no debe confundirse con plagio.
    \item \textbf{Entrega:} sistema \textbf{desplegado en producci\'{o}n}, reproducible (Docker), dise\~{n}ado como apoyo al revisor humano.
\end{itemize}
\vspace{0.1cm}
{\small\itshape\color{textsec} Stack: Python, PyTorch, Hugging Face Transformers, sentence-transformers, FAISS (HNSW), BM25, MongoDB, Docker.\\ M\'{a}s detalles: \href{https://purpplealien.github.io/proyecto-terminal.html}{purpplealien.github.io/proyecto-terminal.html}}

\section*{Capstone Project I: Paraphrase \& Plagiarism Detection System (Bachelor's Thesis)}
\justifying
\small
Dual-mode NLP system (pairwise classification + full-document analysis) for academic plagiarism detection at UAM-I: the institutional TESIUAMI corpus of \textbf{21{,}128 theses} across all three divisions (CBI, CBS, and CSH) plus an external scientific corpus of $\sim$250 million works (OpenAlex, Semantic Scholar, and Crossref).
\vspace{0.12cm}
\begin{itemize}
    \item \textbf{Architecture:} hybrid retrieval (HNSW semantic + BM25 lexical, RRF fusion) with an int8-quantized cross-encoder classifier, using fine-tuned XLM-RoBERTa/BETO models.
    \item \textbf{Models:} fine-tuned BETO v3 (\textbf{F1 = 0.842} on a clean test set), evaluated with confidence intervals (95\% CI) and a data-leakage audit; matches the previous baseline with orders of magnitude less annotated data.
    \item \textbf{Key finding:} the thesis is that ``data beats architecture'': synthetic data degrades performance and an exhaustive corpus search shows the corpus is original — thematic similarity must not be confused with plagiarism.
    \item \textbf{Delivery:} system \textbf{deployed in production}, reproducible (Docker), designed to support human reviewers.
\end{itemize}
\vspace{0.1cm}
{\small\itshape\color{textsec} Stack: Python, PyTorch, Hugging Face Transformers, sentence-transformers, FAISS (HNSW), BM25, MongoDB, Docker.\\ More details: \href{https://purpplealien.github.io/proyecto-terminal.html}{purpplealien.github.io/proyecto-terminal.html}}
